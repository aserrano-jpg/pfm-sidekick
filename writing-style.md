# Writing Style Guide

**Always reference this file when creating any internal content for [Name].**
Internal content includes: Atlas KR updates, MBR sections, Slack summaries,
Confluence pages, email drafts, one-pagers, and reporting narratives.

For external content, also reference the Atlassian Brand Voice & Tone guide:
https://hello.atlassian.net/wiki/spaces/IMKT/pages/4828993500

---

## Core principles

- Write like a smart, direct colleague. Not a consultant, not a press release.
- Lead with the "so what" — data first, context second
- Specific over vague, always. Name the number. Name the channel. Name the motion.
- Short > long. If it can be a sentence, don't make it a paragraph.
- Internal reporting (Atlas, MBR, Slack) = direct and data-forward. No fluff.

## AI writing tropes to avoid

Apply these rules to ALL content.

### Word choice

**Never use:**
- "—"
- "delve", "certainly", "utilize", "leverage" (as verb), "robust", "streamline", "harness"
- "quietly", "deeply", "fundamentally", "remarkably", "arguably" as magic adverbs
- "tapestry", "landscape", "paradigm", "synergy", "ecosystem", "framework" as grandiose nouns
- "serves as", "stands as", "marks as", "represents" — just use "is"
- "it's worth noting", "importantly", "interestingly", "notably" as filler transitions
- "let's dive in", "let's unpack", "let's break this down", "let's explore"
- "here's the kicker", "here's the thing", "here's where it gets interesting"
- "think of it as...", "imagine a world where..."
- Invented compound labels: "supervision paradox", "acceleration trap", "workload creep" etc.

### Sentence structure

**Never do:**
- The "It's not X — it's Y" pattern.
- "Not X. Not Y. Just Z." dramatic countdown pattern
- "The result? Devastating." self-posed rhetorical questions answered immediately
- Anaphora abuse — repeating the same sentence opening 3+ times in a row
- Tricolon abuse — rule-of-three used back-to-back repeatedly
- "From X to Y" false ranges where X and Y aren't on a real scale
- Superficial "-ing" phrases tacked onto sentences ("highlighting its importance", "reflecting broader trends")

### Paragraph structure

**Never do:**
- Excessive short punchy fragments as standalone paragraphs for manufactured emphasis
- "The first... The second... The third..." listicle disguised as prose
- Fractal summaries — summarizing what you're about to say, then saying it, then summarizing what you said
- One-point dilution — restating the same argument 10 different ways

### Tone

**Never do:**
- Grandiose stakes inflation ("this will fundamentally reshape how we think about everything")
- False vulnerability ("and yes, I'll be honest here...")
- "The truth is simple" / "history is clear" — asserting rather than proving
- Vague attributions ("experts say...", "industry reports suggest...")
- "Despite its challenges..." dismissal formula
- Historical analogy stacking (Apple didn't build Uber, Facebook didn't build Spotify...)
- "In conclusion", "to sum up", "in summary" — never announce the ending

### Formatting

**Never do:**
- Bold-first bullets (every bullet starting with **Bold keyword:**)
- Em dashes ("—") — never, under any circumstances
- Unicode arrows (→) — use plain text
- Every bullet point in bold

## One-line summary

**Write like a smart person talking to another smart person. Be specific. Be short. Skip the theater.**
